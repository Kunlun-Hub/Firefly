# 2026年8月客诉月报 —— 各项指标计算公式拆解

> 月报成品文件：`2026年8月客诉月报.xlsx`
> 工单源文件：`2026年8月客诉工单.xlsx`（含 3 个明细 sheet：**创建量 / 投诉次数 / 投诉票数**）

---

## 一、基础量（分子/分母的来源）「先理清五个基础量」

| 基础量 | 含义 | 来源 | 月报中对齐的列 |
|---|---|---|---|
| 业务量 C | 发件票数/经手票数，全网用**发件票数**，省区用**经手票数** | 业务量数据（不在工单文件内，另有商品量报表） | 客户投诉率汇总 C 列 |
| 总工单量 D | 创建工单总数（去重后按单） | 工单源「创建量」sheet 总行数 | 客户投诉率汇总 D 列（122214） |
| 投诉次数 E | 进线/投诉发生的次数（同一票可多次） | 工单源「投诉次数」sheet 总行数 | 客户投诉率汇总 E 列（21951） |
| 投诉票数 F | 去重后的投诉单/票数（一票计一次） | 工单源「投诉票数」sheet 总行数，**按"服务所属片区"分组** | 客户投诉率汇总 F 列（20614） |
| 处理量 N | 纳入首响/完结统计的工单量 | 总工单量剔除部分 | 首响率、完结率分母 |

> ⚠️ 关键口径：**省区投诉票数 = 工单源「投诉票数」sheet 按「服务所属片区（即受理省区/管理区）」分组统计的行数**。例如黑龙江 = 358，与月报汇总表 F4=358 完全一致。

---

## 二、「客户投诉率（汇总）」—— 全月核心指标

指标说明：全网客诉率分母为**发件票数**，省区客诉率分母为**经手票数**。

| 指标 | 列 | 公式 |
|---|---|---|
| 本月投诉率（万票客诉率） | G | `= F / C × 10000` |
| 环比 | I | `= (G − H) / H`（H=上月投诉率） |
| 同比 | K | `= (G − J) / J`（J=2025年8月投诉率） |
| 工单率 | L | `= D / C` |
| 首响率 | P | `= O / N`（O=及时首响次数，N=处理量） |
| 完结率 | S | `= R / N`（R=及时完结量，N=处理量） |
| 重复投诉率 | V | `= U / D`（U=重复投诉量，D=总工单量） |
| 重复有责率 | Y | `= X / D`（X=重复有责量，D=总工单量） |
| 三方投诉率（百万票） | AC | `= AA / C × 1000000`（AA=三方票数） |
| 三方有责率 | AD | `= AB / C × 1000000`（AB=有责票数） |

---

## 三、「客诉率（环节）」—— 发件/中转/派件三环节

| 指标 | 列 | 公式 |
|---|---|---|
| 投诉率（万分） | J | 合计行：`= F / 发件票数 D × 10000`；省区行：`= F / 经手票数 C × 10000` |
| 发件投诉率 | K | `= 发件投诉票数 G / 发件票数 D × 10000` |
| 中转投诉率 | L | `= 中转投诉票数 H / 经手票数 C × 10000` |
| 派件投诉率 | M | `= 派件投诉票数 I / 派件票数 E × 10000` |
| 各环节涨幅率 | R/S/T/U | `= (本月 − 上月) / 上月`，即 `(J−N)/N`、`(K−O)/O`、`(L−P)/P`、`(M−Q)/Q` |

---

## 四、「客诉率（快件类型）」—— 电商件/线上订单等

| 指标 | 公式 |
|---|---|
| 8月投诉率 F | `= 8月投诉票数 E / 8月发件票数 D × 10000` |
| 7月投诉率 I | `= 7月投诉票数 H / 7月发件票数 G × 10000` |
| 环比 J | `= (F − I) / I` |
| 线上订单投诉票数 E | `= 合计投诉票数 E3 − 其他类型投诉票数 E5` |

---

## 五、「类型板块」—— 按工单类型

| 指标 | 列 | 公式 |
|---|---|---|
| 工单率（万分） | G | `= 次数 F / '客户投诉率（汇总）'!$C$3 × 10000`（除以全网业务量） |
| 占全部工单比 | H | `= F / 全部工单总次数 F2` |
| 占工单大类比值 | I | `= F / 所属工单大类工单量 Q` |
| 投诉率环比 | N | `= (G − K) / K` |
| 本月工单率 | R | `= 本月工单量 Q / 业务量 C × 10000` |
| 本月占比 | S | `= Q / 工单总量 Q2` |
| 工单率环比 | W | `= (R − U) / U` |

---

## 六、「重复投诉」

| 指标 | 列 | 公式 |
|---|---|---|
| 重复投诉创建率（按类型） | U | `= 重复投诉量 T / 工单量 S` |
| 重复投诉有责率 | Y | `= 重复有责量 X / 工单量 S` |
| 有责占比（有责/重复量） | AB | `= 重复有责量 X / 重复投诉量 T` |
| 重复创建率环比 | W | `= (U − V) / V` |
| 各省区重复投诉率 | AG | `= 重复量 AF / 总工单量 AE` |
| 各省区重复有责率 | AJ | `= 重复有责量 AI / 总工单量 AE` |
| 各省区有责占比 | AL | `= 重复有责量 AI / 重复量 AF` |

---

## 七、「升级投诉」（三方/有责）

| 指标 | 列 | 公式 |
|---|---|---|
| 有责率 | AA | `= 有责票数 Z / 投诉票数 Y` |
| 有责票数差值 | AC | `= 本月有责票数 Z − 上月有责票数 AB` |
| 有责占比（类型） | AI | `= 有责票数 AH / 投诉票数 AG` |
| 投诉占比 | AJ | `= 本类型投诉票数 AG / 全部投诉票数 AG2` |
| 有责占比 | AK | `= 本类型有责票数 AH / 本类型投诉票数 AG` |
| 本月占比 | U | `= 本月票数 S / 总数 S2` |

---

## 八、「全网一次性解决率」

| 指标 | 列 | 公式 |
|---|---|---|
| 一次性解决率 | G | `= 一次性解决量 E / 工单总量 D`（合计：95838 / 99104 = 0.967） |
| 差值（是否达标） | I | `= 一次性解决率 G − 达标值`（达标值约 0.96，达标标"是"） |
| 环比 | L | `= (G − K) / K` |

---

## 九、「异常影响值」—— 剔除异常网点 / 产品中心

| 指标 | 列 | 公式 |
|---|---|---|
| 工单率 | I | `= 总工单量 D / 业务量 C` |
| 投诉率 | J | `= 投诉票数 F / 业务量 C × 10000` |
| 重复投诉率 | K | `= 重复投诉量 G / 总工单量 D` |
| 重复有责率 | L | `= 重复有责量 H / 总工单量 D` |
| 剔除异常网点后 工单率 | Q | `= (D − 异常工单量 M) / C` |
| 剔除异常网点后 客诉率 | R | `= (F − 异常投诉量 N) / C × 10000` |
| 剔除异常网点后 重复投诉率 | S | `= (G − 异常重复量 O) / (D − M)` |
| 剔除异常网点后 重复有责率 | T | `= (H − 异常有责量 P) / (D − M)` |
| 剔除产品中心后（Y/Z/AA/AB） | — | 同上述逻辑，分母替换为"剔除产品中心后的量"（U/V/W/X） |
| 剔除异常+项目后（AG/AH/AI/AJ） | — | 同上述逻辑，分母替换为 AC/AE/AF 对应的剔除量 |

## 十、一句话速记

- **客诉率（万票）** = 投诉票数 / 业务量 × 10000（全网分母用发件票数，省区分母用经手票数）
- **工单率** = 总工单量 / 业务量
- **首响率** = 及时首响次数 / 处理量
- **完结率** = 及时完结量 / 处理量
- **重复投诉创建率** = 重复投诉量 / 总工单量
- **重复投诉有责率** = 重复有责量 / 总工单量
- **三方投诉率（百万）** = 三方票数 / 业务量 × 1000000
- **一次性解决率** = 一次性解决量 / 工单总量
- **所有环比/同比/涨幅** = (本月值 − 上月值) / 上月值
- **异常/产品项目剔除口径** = (总量 − 剔除量) / 业务量，重复类为 (总量 − 剔除量) / (工单总量 − 剔除工单量)
